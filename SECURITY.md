# Сообщения об уязвимостях ARGUS

Не публикуйте сведения об уязвимости, эксплойт или реальные данные в открытой
задаче. Отправьте сообщение на **support@devitex.software** с темой
`ARGUS security report`. Не прикладывайте реальные секреты или персональные
данные; для воспроизведения используйте обезличенный пример.

В сообщении укажите затронутую версию, компонент, условия эксплуатации,
воспроизведение на тестовых данных и возможное влияние. Не проверяйте проблему
на чужих установках без разрешения их владельцев.

Срок первого ответа пока не установлен и будет указан после запуска процесса
обработки сообщений. Получение письма само по себе не означает признания
уязвимости или срока исправления.

Поддерживаемые версии и даты окончания поддержки будут указаны после первого
публичного релиза. Исправления безопасности публикуются с описанием влияния
и инструкцией по обновлению.
