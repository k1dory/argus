- **Слепой разбор: доработки по повторному ревью #13.** При ошибке `INSERT … FORMAT
  JSONEachRow` журнал консоли получает только заголовок запроса до имени формата: строки
  (вердикт агента, комментарий) больше не попадают в лог. `since` выгрузки меток сравнивается
  с точностью до наносекунд — доли мельче миллисекунды не расширяют период назад. Тест
  политик `argus_ro_blind` покрывает JOIN, подзапрос, `merge()`, `system.*` и вердикт без
  строки инцидента.
