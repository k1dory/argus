- **«Обзор» сначала показывает, что требует внимания.** Первым блоком — недоступный
  движок корреляции, остановленный приём, молчащие источники, эскалации и открытые
  критичные инциденты со ссылками; ниже лента последних инцидентов. В подписях плиток
  указан период («Событий за 24 часа»), вместо «Классов источников» — «Молчат N / M»,
  классы источников кликабельны, а классы без событий за период выделены.
- **«Источники»: молчащие отдельно от работающих.** Вкладки «Все / Молчат / Работают»,
  группы с подсветкой молчащих, статус, ритм и последний приём одной фразой, нулевой
  поток подсвечен как остановка приёма. Лента событий показывается только для
  выбранного источника (общая — в «Журнале»), адреса приёма — в свёрнутом блоке
  «Как подключить источник».
- **Дашборды: список вместо таблицы, создание — кнопкой «Новый дашборд».**
- **Доска дашборда: одна плашка вместо одинаковой ошибки в каждой панели.**
  Технические подробности видны только администратору, у упавших панелей вместо «0 мс»
  стоит «ошибка». Исправлено: при заданном точном интервале подсвечивался пресет
  «24 часа». Точный интервал свёрнут в «Свой интервал» и показывается чипом со сбросом,
  кнопка «Удалить» перенесена в редактор.
- **Редактор дашборда больше не теряет несохранённые правки.** Переход по ссылке
  внутри консоли и кнопка «Назад» браузера спрашивают «Сохранить и уйти / Уйти без
  сохранения / Остаться». Удалённую панель можно вернуть из уведомления. Строка
  «Сохранить» закреплена сверху, автообновление выбирается из списка, справка по
  JSON свёрнута.
