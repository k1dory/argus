- **Консоль: время молчания источника — по часам ClickHouse.** У источников, которые пишут в `events` напрямую, без heartbeat, «сейчас» бралось из `Date.now()` Node: если часы консоли и базы расходились, `silent_for_sec` и признак «жив» сдвигались на эту разницу. Теперь `now()` возвращают сами запросы.
