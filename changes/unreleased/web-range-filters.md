- **Консоль: диапазонные фильтры на всех списках.** Уровень и серьёзность — порогом
  «не ниже / не выше» (`level_min` / `level_max`), время — пресетом (`range`, синоним
  `period`) или точным интервалом UTC (`from` / `to`), числовые поля — «от–до»
  (`<поле>_min` / `<поле>_max`: события, алерты, критичные, CVSS, инциденты, доля ложных,
  EPS), последний приём источника — `seen_from` / `seen_to`. Параметры живут в URL —
  ссылкой с фильтрами можно поделиться. Старые ссылки работают: `level=` на «Инцидентах»
  — точный уровень, `level=N` у алертов Wazuh — «не ниже N», `sev=N` журнала — «не ниже N».
  Пустой список называет активные фильтры. `/api/incidents` и `/api/search` принимают те
  же параметры (OpenAPI обновлён). Условия — только параметрами ClickHouse; окно времени
  сравнивает колонку с константой и отсекает партиции и гранулы по `ts`/`timestamp`
  (лента «Источников» — skip-индексом `received_at`). Миграций нет.
