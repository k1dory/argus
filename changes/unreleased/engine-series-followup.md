- **Движок: серия порога обрывается, когда группа опустилась ниже порога** (ревью #113). Держит ли группа порог — по окну до нового события: `count: 1` при окне 1m и событиях раз в 2 минуты даёт две сработки, а новый инцидент после `auto_close` не получает старых доказательств.
- **Повторные достижения порога без копий окна.** Окно группы — представление поверх общего массива событий группы, который только дописывается; сработка — его срез. 40 тыс. событий, `distinct: 301` и 300 повторов больше не выделяют ~100 МиБ.
- **Прошлый запуск движка ищется за весь срок хранения events** (180 дней), а не за 30: после месяца работы аварийный рестарт больше не считается первым запуском. Поиск идёт в фоне — детект его не ждёт.
- **Причина `oom` — только по приросту `oom_kill`** с прошлого старта (`engine.started` хранит снимок счётчика): старый OOM живой cgroup не превращает каждый следующий обрыв в OOM.
