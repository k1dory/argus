- **Движок: сканы склеиваются по подсети.** Правило с `collapse: {by: src.net, group: …}`
  заводит один инцидент на подсеть источника (`/24`, IPv6 `/48`) для всей группы правил;
  порог по-прежнему на адрес. `net-inbound-portscan`, `-sweep` и `-service-hammer` — группа
  `inbound-scan`: адрес, который сканировал и долбил SSH, и соседние адреса подсети — один
  инцидент вместо десятков. Блокировка — по каждому адресу тем же респондером, как у
  отдельного инцидента, по правилу этого адреса. Карточка инцидента показывает адреса
  подсети со статусом блокировки. Миграция `0035_incidents_members` (колонки
  `incidents.members`, `members_dropped`) — применить до обновления движка. Открытые
  инциденты адресов задним числом не склеиваются.
