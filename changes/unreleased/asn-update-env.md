- **`asn-update.sh`: порог из `.env` стека, абсолютный путь каталога.** Порог
  `ASN_DB_MIN_ROWS` скрипт берёт из `.env`, тем же значением, что получает коллектор; cron
  этот файл не экспортирует. Раньше по cron с умолчанием 10000 ставилась таблица, которую
  коллектор с порогом выше отвергал, и после рестарта ASN пропадал. `.env` не исполняется:
  читается только эта строка. Относительный каталог без `./` (`data`) приводится к
  абсолютному пути: `docker run -v` принимал его за имя тома.
