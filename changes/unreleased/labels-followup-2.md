- **Журнал консоли не цитирует данные из ошибок ClickHouse.** Диагностика ClickHouse
  приводит фрагменты входных данных («Cannot parse input: '…'», «Cannot parse string '…'»):
  строку INSERT с вердиктом агента или подставленный параметр аудита. Содержимое кавычек
  теперь заменяется на «…» и в журнале, и в тексте ошибки. У любого INSERT в журнал идёт
  только заголовок «INSERT INTO таблица (колонки)» — без FORMAT-данных, VALUES и SELECT с
  литералами, в том числе при комментарии перед именем формата. `since` выгрузки меток
  после 2262 года (предел DateTime64(9)) даёт пустую выгрузку, а не ошибку.
