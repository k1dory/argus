- **Ошибки ClickHouse без текста исключения.** Текст исключения ClickHouse цитирует данные
  запроса (строку INSERT с вердиктом агента, параметр аудита, значение колонки), а
  замаскировать его надёжно нельзя. В журнал консоли и в сообщение ошибки теперь идут только
  код, имя исключения из списка ClickHouse 24.8 по этому коду (`код 60 (UNKNOWN_TABLE)`),
  HTTP-статус и `query_id` — полный текст оператор смотрит в `system.query_log`. У INSERT в
  журнал идёт только заголовок запроса без данных. `since` выгрузки меток после 2262 года
  даёт пустую выгрузку, а не ошибку.
  Запросы консоли и панелей идут с `wait_end_of_query=1`: ClickHouse буферизует ответ, и
  ошибка посреди выдачи (в том числе `Poco::Exception`/`std::exception`) приходит HTTP-ошибкой
  с `X-ClickHouse-Exception-Code`, а не строкой в конце тела со статусом 200 — её больше не
  принять за данные (экспорт поиска) или успешную запись. Ошибка определяется только по
  статусу и заголовку: строка «Code: 1.» в данных остаётся данными. В SQL панели явный
  `FORMAT` запрещён (формат ставит консоль). Ошибка панели — «код N (ИМЯ)» и `query_id`, без
  тела ответа; ответ не в JSON — «ответ не JSON» без цитаты данных.
