- **Консоль: сканы снаружи свёрнуты по подсети.** Открытые инциденты правил
  `a41c-net-070`/`071`/`072` в ленте сгруппированы по подсети источника (`/24`, IPv6 `/48`):
  одна строка «подсеть: N адресов, правила, первое и последнее, старший уровень» вместо
  десятков. Раскрытие показывает инциденты как есть со статусом блока каждого; групповые
  действия (взять, назначить, завершить с меткой) — с подтверждением числа инцидентов.
  «Показать списком» — прежний вид. Движок и автоответ не меняются, миграции нет.
