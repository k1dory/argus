- **Диапазонные фильтры: исправления по ревью #77.**
  - Неизвестный пресет (`range=constructor`) на дашборде больше не растягивает окно до 1970 года: пресеты проходят через белый список (`parseRange` проверяет только собственные ключи).
  - `/api/search` разбирает окно тем же парсером, что страница: `period`, потолок 400 дней, один `to` даёт сутки до него.
  - Порог «не выше» по шкале (`level_max=High`) больше не пропускает пустую и неизвестную серьёзность.
  - Применение одного интервала не снимает прежний `level=`.
  - В журнале перестановка `level_min=8&level_max=0` даёт 0…8, а не 1…8.
  - `period=30d` применяется на «Субъектах» и дашборде.
  - Выбор источника и смена пресета паспорта сохраняют остальные фильтры.
