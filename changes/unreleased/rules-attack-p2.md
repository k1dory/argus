### Движок

- Модификатор правил `field|internal: true|false` — адрес из своих сетей. Сети берутся из `INTERNAL_NETS`, а если он пуст — те же умолчания, что у коллектора для `attrs.scope`: RFC 1918, 100.64/10, loopback, link-local, ULA. Адрес сравнивается через netip, поэтому регистр, сокращённая запись IPv6 и IPv4-mapped не важны. Ошибочный CIDR в `INTERNAL_NETS` не даёт загрузить правило.

### Правила

- `fw-inbound-deny-burst` (a41c-net-073): источники из своих сетей исключаются через `src.ip|internal`, а не регуляркой. Учитываются свои белые блоки из `INTERNAL_NETS` и 100.64/10; событию не нужен `attrs.scope`.
- `proxy-foreign-access` (a41c-net-076) остаётся сигналом по географии без техники ATT&CK (тег `argus.geo`). Обращения из чужой страны сами по себе не говорят ни о скане, ни об учётной записи.
- Новое правило `proxy-foreign-account` (a41c-net-077, medium): успешный запрос вошедшего пользователя (`actor.kind=user`, `outcome=success`) из чужой страны, группировка по учётной записи. Метки: `attack.initial_access` и T1078. Срабатывает только с прокси, которые передают пользователя; NetBird-прокси без аутентификации его не передаёт.
- В тесте на технику у правил ИБ исключения перечисляются поимённо, у каждого указана причина.
