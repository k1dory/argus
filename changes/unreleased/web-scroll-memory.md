- **Консоль: прокрутка переживает F5.** Страницы консоли приходят потоком (скелет → данные), поэтому штатное восстановление браузера срабатывало на короткой странице и оставляло список наверху — после перезагрузки «Инцидентов» приходилось листать заново. Теперь положение запоминается по адресу (путь + фильтры) в sessionStorage и возвращается, когда страница дорисована; только при перезагрузке и «назад/вперёд», обычные переходы открываются сверху. Пользователь начал листать сам — восстановление прекращается.
