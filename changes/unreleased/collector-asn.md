- **Коллектор: ASN публичных адресов в событиях.** `attrs.src_asn` / `src_as_org` и
  `attrs.dst_asn` / `dst_as_org` по локальной таблице iptoasn.com (`ASN_DB_FILE`, каталог
  `ASN_DB_DIR` монтируется в `/asn`). Внешних запросов нет. Таблица перечитывается по mtime и
  проверяется при загрузке; битая не заменяет прежнюю. Поля из тела события удаляются всегда,
  у частных и зарезервированных адресов их нет. Обновление — `scripts/asn-update.sh` по cron,
  в роли argus — `argus_asn: true`. Без `ASN_DB_FILE` поведение прежнее, только присланные
  поля ASN больше не сохраняются. Миграций нет.
