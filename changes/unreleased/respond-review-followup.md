- **Автоответ: доработки после ревью исключения адреса (#75).**
  - **Снятие после рестарта не сообщает ложный успех.** «200 — блок уже снят» — только для повтора недописанного решения тем же оператором. Если по журналу у адреса есть блок (done), а список активных блокировок рестарт потерял, ответ — 422 с подсказкой снять блок на NGFW вручную или дождаться TTL; автоблокировка по этим инцидентам отменена.
  - **Длинное окно чтения журнала** для ключей, хоть раз отложенных исключением, читает их историю целиком: более поздний manual или blocked больше не теряется, и отменённое состояние после рестарта не возвращается.
  - **Отозванное исключение** (надгробие) не считается действующим и в проверке свежих событий инцидента.
