- **Фрагменты changelog вместо правки «Не выпущено».** Каждый PR кладёт запись в свой файл
  `changes/unreleased/<ветка>.md`, `CHANGELOG.md` правит только релиз:
  `scripts/changelog-release.sh <версия>` собирает фрагменты и прежние записи «Не выпущено»
  в раздел версии и удаляет файлы. CI (job `changelog`) отклоняет PR, который меняет
  `CHANGELOG.md` без `VERSION`; релиз не собирается с несобранными фрагментами. Параллельные
  PR больше не конфликтуют в одном месте файла.
