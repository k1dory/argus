- **Коллектор: события с часами в будущем больше не выпадают из окон правил.**
  - **Замена времени.** Если `ts` дальше `COLLECTOR_CLOCK_SKEW_MAX` (по умолчанию 10m, 0 —
    выключено) от момента приёма, `ts` = время приёма, исходное — в `attrs.ts_original`.
    Это касается syslog, NDJSON, файлов и NetFlow. Присланный в событии `ts_original` не
    принимается.
  - **Сигналы.** Раз в минуту по каждому отправителю приходит событие `argus.collector` /
    `collector.clock_skew`, ведётся счётчик `argus_collector_clock_skew_total`.
  - **Повод.** На argus1 `nas.qnap` (RFC 3164 без пояса) писал время на 3 ч вперёд.
