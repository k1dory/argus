- **«Субъекты»: подсчёт активности больше не упирается в таймаут.** На стенде с 79 персонами
  и 374 алиасами список падал по таймауту 20 с: предфильтр `hasAny` со всеми значениями
  сравнивал каждую строку с каждым значением, а bloom-индекс при сотнях значений не отсекает
  гранулы. Теперь при числе значений больше 32 предфильтр — `IN` по колонке каждого вида
  алиаса. Подсчёт персон идёт за один проход хеш-поиском ключей строки (`transform`), без
  сотен веток OR, и укладывается в 2 с на 180 млн строк. Счётчики те же, что у паспорта,
  включая интервалы действия алиасов и регистр. Паспорт одного человека (до 32 значений)
  по-прежнему отсекает гранулы индексом `idx_actor_keys`.
