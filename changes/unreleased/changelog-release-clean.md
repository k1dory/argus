- **`scripts/changelog-release.sh` — только с чистого дерева.** Фрагменты должны быть
  закоммичены; при незакоммиченных, staged или неотслеживаемых изменениях в `changes/`,
  `CHANGELOG.md` или `VERSION` скрипт отказывает. Фрагменты читаются из индекса Git, не с
  диска (симлинк в Git — отказ). При сбое после начала изменений печатается команда отката
  (`git checkout HEAD -- CHANGELOG.md changes && git reset …`), после неё повтор — обычная
  сборка. Снимков индекса и досборки больше нет.
