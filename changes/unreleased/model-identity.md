- **Датасет: ответ модели без опознанной ревизии в метрики не попадает (ревью codex #81).**
  Если в ответе System One `model` отсутствует, пуст, `null` или состоит из пробелов, ответ
  записывается как ошибка модели. Псевдоним из конфигурации (`ARGUS_LAYA_MODEL` /
  `ARGUS_JEV_MODEL`) ревизию не подтверждает: за ним выкатывают новые версии. Два пустых `model`
  тоже больше не считаются одной ревизией.
