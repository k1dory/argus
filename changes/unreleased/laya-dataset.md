- **`engine dataset export` / `engine dataset eval` — датасет и замеры моделей решений.** Выгрузка
  в JSONL (`argus-dataset/v1`) инцидентов, которые завершил человек с меткой (`labeled_by_human`),
  с обезличенным состоянием, `group_id` случая, разбиением train/holdout (25 % по группе) и
  потолком записей на правило (`--max-per-rule`, по умолчанию 100). По флагу `--models laya,jev`
  тем же вопросам отвечают модели System One: `laya-serve` (`ARGUS_LAYA_ENDPOINT`,
  `ARGUS_LAYA_MODEL`, `ARGUS_LAYA_TOKEN`) и Jev (`ARGUS_JEV_ENABLED=1`, `ARGUS_JEV_API_KEY`,
  `ARGUS_JEV_ENDPOINT`, `ARGUS_JEV_MODEL`). Инциденты с ПДн в Jev не отправляются никогда.
  `eval` считает acc, soft acc, Brier, ECE, NLL по слепой части holdout, подбирает температуру
  и пороги автозакрытия и подсказки на train. Без флага `--models` внешние вызовы не делаются.
  Миграций нет. ML-часть проекта — https://huggingface.co/k1dory/laya-argus.
- **Состояние для моделей решений — по белому списку, без свободного текста (ревью codex #64).**
  В состояние попадают правило, уровень, теги, источники и число событий. Субъект и узел заменяются
  псевдонимами HMAC с солью, своей на каждую выгрузку; соль в JSONL не пишется. Из строк цепочки и
  событий обогащения известного формата берутся время, источник, узел, действие и деталь. От детали
  остаётся псевдоним адреса (с портом) или учётки, измерение с единицей из постоянного списка либо
  только тип объекта (`[path]`, `[url]`, `[text]`) с расширением из постоянного списка. Пути, URL,
  причины срабатывания и прочий свободный текст не передаются вообще, их заменяет счётчик
  отброшенных строк. Из CMDB берётся только критичность по шкале. Похожие инциденты, владелец и
  заметка не передаются. `group_id` — HMAC с той же солью. Разбиение train/holdout от соли не
  зависит и одинаково во всех выгрузках.
- **Событие обогащения с ПДн помечает инцидент `pii=1`.** До сих пор строки EDR/NGFW с ПДн
  попадали в обогащение инцидента без флага и могли уйти в облачные маршруты. Теперь такие инциденты
  не отправляются ни в облачного аналитика, ни в Jev.
- **Ошибки System One — только класс** (transport / timeout / http N / malformed response /
  invalid answer). Текст ответа, заголовки и ошибки транспорта, где бывает эхо ключа, в лог и в
  датасет не попадают.
