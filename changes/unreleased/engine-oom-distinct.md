- **Движок: оценка правил с порогом линейна по размеру группы (цикл OOM на argus1 02.11–04.11).**
  - Прежде при сдвиге окна группы серия обрывалась, и каждое следующее событие заводило новую сработку с копией всего окна, а `distinct` каждый раз строил множество значений по окну. Сканер с 40 тыс. событий в группе (a41c-net-070/071) давал на одну оценку 53 тыс. сработок и 30 ГиБ выделенной памяти.
  - Теперь серия продолжается, пока группа держит порог; `distinct` считается по счётчикам значений окна; окно сдвигается без копий; сработка дописывается по индексу. Та же группа — 2 сработки и 7 МиБ. Правила без порога склеивают события от начала сработки, как раньше (`dedupe: 24h` — раз в сутки).
  - Тест памяти и бенчмарк: `internal/eval/distinct_memory_test.go` (порог по байтам и аллокациям).
- **Самонаблюдение: `engine.started` / `engine.stopped` / `engine.restarted`.** Старт после оборванного запуска пишет `engine.restarted` с причиной (`oom` по `oom_kill` cgroup, иначе `unclean`), метрика `argus_engine_unclean_restarts_total`. Правило `a41c-ops-069` (`rules/ops/engine-restart-loop.yml`, high): два оборванных старта за 30 минут.
