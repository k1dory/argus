- **«Источники»: новая панель фильтров коллекторов.** Быстрый выбор «Все / Есть
  события / Без событий» за последний час, число результатов и снимаемые метки
  условий. Точные даты UTC и числовые пороги раскрываются по кнопке «Фильтры»;
  отмена отбрасывает черновик. Панель переносится на узком экране, нулевые пороги
  и отдельные фильтры ленты сохраняются. Запросы к ClickHouse и REST API не менялись.
