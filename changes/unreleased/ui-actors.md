- **Субъекты: список про риск.** Плитки «С инцидентами», «Без владельца», «Последняя
  активность», «Активны»; персоны по инцидентам и свежести, неактивные свёрнуты. Один
  переключатель периода на странице — и учётки без владельца считаются за тот же
  период. Пороги событий и инцидентов спрятаны в «Точные фильтры», вместо них вкладки
  «Все · С инцидентами · Активные · Служебные». Подразделение подписано «Отдел».
- **Кому принадлежит: ответ наверху.** «X сейчас принадлежит Y» с кнопкой паспорта,
  «сейчас ничьё» с формой привязки для администратора, «несколько владельцев» с
  закрытием лишнего алиаса на месте. Подписи источника и пометок алиаса человеческие,
  отказы в «где встречалось» видны, ссылки в паспорт сохраняют период, пустой экран —
  с примерами и недавними поисками. `/actors/by-alias` теперь только переадресует:
  в паспорт или в «Кому принадлежит».
- **Привязка алиаса больше не действует на всю историю по умолчанию.** Дата начала —
  сегодня (UTC); «на всю историю» — отдельный флажок с предупреждением, без него
  пустая дата отклоняется сервером. Предупреждения для общих учёток (root, admin…),
  IP и хостов; выбор персоны — поиском по имени и id.
