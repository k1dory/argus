- **Коллектор: атрибуты происхождения нельзя подставить ни одним путём приёма.** HTTP `/ingest/*` и S3 NDJSON больше не принимают присланные `peer_cn`, `scope`, `transport`, `ts_original` (а `peer` — только адрес соединения); `scope` всегда считается коллектором по адресам события, без двух адресов его нет. Раньше держатель ingest-токена мог задать `scope=internal` для внешнего потока, а автор S3-объекта — чужой `peer`/`peer_cn` (и сводку `collector.clock_skew` на чужое устройство).
- **Коллектор: чистка управляющих символов за один проход.** Склейка C1 после удаления C0 (`\xc2\x00\x80`) снимается сразу, без повторных проходов — глубокая вложенность больше не даёт квадратичной работы на приёме.
