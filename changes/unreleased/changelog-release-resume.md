- **`scripts/changelog-release.sh`: откат и досборка.** Если замена CHANGELOG.md не
  удалась, индекс Git восстанавливается из копии, сделанной до изменений, — staged-правки
  фрагментов и чужие staged-изменения не теряются (раньше `git reset` возвращал их к
  HEAD). Если после замены не все фрагменты удалось удалить, повторный запуск той же
  версии завершает релиз: раздел уже есть, текст каждого оставшегося фрагмента в нём —
  удаляются только фрагменты, без второго раздела и дублей.
