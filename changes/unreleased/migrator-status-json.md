- **Выкатка читает статус миграций, а не лог migrator.** `scripts/migrate.sh` при выходе
  пишет `run/migrator/migrate.json`: код выхода, этап, файл миграции (имя из каталога),
  последнюю применённую, код ошибки ClickHouse и имя из `errorCodeToName`, имена переменных
  с дефолтными паролями, id запуска. Роль `argus` выводит только эти поля (формат проверяется
  целиком, id запуска сверяется с контейнером, чтобы не показать статус прошлого прогона);
  `docker compose logs migrator`, где упавший `ALTER USER` содержит хеш и соль, не читает.
  Каталог `run/migrator` монтируется в migrator (`MIGRATE_STATUS_DIR=/status`).
