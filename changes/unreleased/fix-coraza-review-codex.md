- **Coraza: подделка узла, категорий и итога транзакции (ревью codex).** Coraza-caddy пишет в
  `server_id` заголовок Host клиента: такой `server_id` (совпадает с Host или Host в аудите нет)
  больше не становится узлом — узел берётся по отправителю, и один WAF не размножается в «три
  узла» для `waf-scanner-multihost`. Текст msg перед метаданными Coraza не экранирует: поддельный
  `[file …] [tag "attack-rce"]` из заголовка запроса больше не задаёт категорию — метаданные
  берутся с последнего `[file "…"]`. «Access allowed» не считается итогом транзакции
  (`allow:phase`/`allow:request` пропускают лишь часть фаз, затем возможен deny).
  Следующие круги ревью: маркер WAF в JSON-логе Caddy распознаётся и экранированным
  (`Coraza:\u0020`); порт в Host снимается до упора (`[a:8443]:443`); Coraza без части H аудита
  (нет `producer`) узнаётся по `timestamp`/`unix_timestamp`; «Access allowed» не итог даже у
  949110. Выбор разборщика CEF/LEEF по содержимому строки и метаданные error-лога ModSecurity
  (неэкранированные msg/uri) подделываются данными запроса — строковые эвристики ломали
  настоящие записи, поведение прежнее, решение отдельной задачей (формат по источнику, JSON-аудит).
