- **Тест `sources-rhythm-ch`: метка фикстуры cap — по часам ClickHouse.** «Сейчас» берётся из `now()` CH, свежесть прежних молчащих источников — из их `last_ts` (тоже часы CH), а не из `silent_for_sec`, который считается по часам Node. Нижняя граница (baseline 61:00–61:02) больше не валит предусловие: cap ставится на секунду новее самого свежего источника. Если места до окна events_1h нет, тест ждёт, а не падает.
- **Тест `sources-rhythm-ch`: ожидание ограничено, baseline пересчитывается.** Настройка cap — цикл: baseline, `now()` ClickHouse и метка cap считаются заново после каждого ожидания; ждём также, пока активный источник прошлого прогона не пересечёт границу часа (иначе два отчёта подряд расходились). Ждать больше 90 с нельзя — общая блокировка live-тестов; тогда тест пропускается с пояснением.
- **Консоль: порядок активных источников детерминирован.** При равном `events_1h` — по имени (`ORDER BY events_1h DESC, source`): раньше два открытия страницы подряд могли показать разный порядок.
