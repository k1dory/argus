# Свои правила

Каталог пользовательских правил движка (`RULES_USER_DIR`, в compose — `/etc/argus/rules.d`,
на хосте — `ARGUS_USER_RULES_DIR`, по умолчанию этот каталог). Формат — как у `rules/`.

Поставляемые правила движок берёт из своего образа: их версия всегда совпадает с версией
движка. Правило здесь с тем же `id`, что у поставляемого, отвергается (событие
`argus.system` / `rules.rejected`, метрика `argus_engine_rules_rejected`), а не подменяет
штатный детект. Чтобы изменить поставляемое правило, скопируйте его сюда под новым `id`.
